Privacy Policy

Last updated: 2026-09-30

This policy explains how Blog Keyword Research ("the tool") handles data. The tool is used only by its operator.

Data the tool accesses

  • Keyword ideas and search-volume statistics returned by the Google Ads API for the operator's own Google Ads account.
  • OAuth credentials for the operator's own Google account, used only to call the Google Ads API.

Google user data

  • Only the operator signs in. The tool does not request, receive, or store any other user's Google data.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How data is used and stored

  • Keyword statistics are used only to choose blog topics.
  • They are stored on the operator's own computer. OAuth credentials are stored locally and are never published.
  • Data is not sold, shared with third parties, or used to advertise to individuals.

This website

This site is a static page hosted on GitHub Pages. It has no forms, accounts, or analytics. GitHub may log standard request information as described in the GitHub Privacy Statement.

Deletion and contact

To ask a question or request deletion of any data, email dydtlsrl@gmail.com. The operator can revoke the tool's access at any time from their Google account security settings.
